# v0.5.0 发布清单

本文档用于 `v0.5.0` 发布准备，覆盖版本锚点、发布前验证、tag / GitHub Release 操作，以及 stable Formula 回填步骤。

## 发布目标

- 版本号：`0.5.0`
- Git tag：`v0.5.0`
- 发布分支：`main`
- 发布定位：发布前进程级 E2E 门禁（沙箱 + 命令桩）+ `release.yml` 打 tag 自动门禁，修复 `set -e` 下 `((count++))` 的隐藏退出码缺陷

## 发布前确认

- 工作区变更已审阅完毕，确认没有不应进入 `v0.5.0` 的临时改动。
- [VERSION](../VERSION) 文件内容为 `0.5.0`（单一权威来源）。
- [bin/macos-scripts](../bin/macos-scripts) 的 fallback 版本为 `0.5.0`。
- [bootstrap/install.sh](../bootstrap/install.sh) 的 fallback 版本为 `0.5.0`。
- [README.md](../README.md) 中 bootstrap、release publish / verify 示例均使用 `v0.5.0`。
- [releases/v0.5.0-release-notes.md](./v0.5.0-release-notes.md) 已与本次发布内容一致。

## Tag 与 Release 操作

确认 `main` 已经是待发布提交后执行：

```bash
git checkout main
git pull --ff-only origin main
git add VERSION bin/macos-scripts bootstrap/install.sh README.md Formula/macos-scripts.rb releases/v0.5.0-release-notes.md releases/v0.5.0-checklist.md
git commit -m "Prepare release v0.5.0"
git push origin main
git tag -a v0.5.0 -m "Release v0.5.0"
git push origin v0.5.0
```

发布后校验：

```bash
git ls-remote --tags origin | grep "refs/tags/v0.5.0$"
curl -I https://raw.githubusercontent.com/anzihenry/scripts/v0.5.0/bootstrap/install.sh
./bin/macos-scripts release verify v0.5.0
```

## GitHub Release 操作

```bash
./bin/macos-scripts release publish v0.5.0 --yes
```

底层等价命令：

```bash
bash maintain/github_release_publish.sh \
  --tag v0.5.0 \
  --notes-file releases/v0.5.0-release-notes.md \
  --update-existing \
  --yes
```

## Stable Formula 回填

由于 GitHub 源码归档 `sha256` 需要基于远端 `v0.5.0` tarball 计算，打完 tag 后再更新 [Formula/macos-scripts.rb](../Formula/macos-scripts.rb)：

```bash
# 注意：必须从 refs/tags/<tag> 归档下载（tag 归档前缀为 scripts-<tag>），
# 不要用 tar.gz/<sha>（提交归档前缀为 scripts-<sha>，字节不同导致 sha 不同）。
curl -L https://codeload.github.com/anzihenry/scripts/tar.gz/refs/tags/v0.5.0 -o /tmp/macos-scripts-v0.5.0.tar.gz
shasum -a 256 /tmp/macos-scripts-v0.5.0.tar.gz
```

然后把 Formula 中的 `url` / `sha256` 更新到 `v0.5.0`（`url` 已在准备提交中更新，`sha256` 回填），再补一次提交推送到 `main`。

> 要点：tag 一旦冻结不要再移动（移动会改变 tarball 使 sha 失效）；回填只更新 main 上的 Formula。发布门禁（`release.yml`）的 Formula 实装步骤走 `brew tap` + `brew install <tap>/macos-scripts`，读取 main 分支 Formula，与 tag 内 Formula 解耦。

## 发布后检查

- 确认 `curl .../v0.5.0/bootstrap/install.sh | zsh -s -- --dry-run --yes` 可以完整跑通（纯管道场景下 `read` 拿不到终端输入，必须带 `--yes`，否则会在“是否继续”确认处取消）
- 确认 release 页面文案与 [releases/v0.5.0-release-notes.md](./v0.5.0-release-notes.md) 一致（可用 `gh release view v0.5.0 --json body -q .body` 比对）
- 完成 Formula 回填后，再次验证 `brew install anzihenry/scripts/macos-scripts` 指向 `v0.5.0`
