## v0.3.0

这个版本把 `macos-scripts` 从“已完成一轮模块拆分”继续推进到“CLI 层和核心流程层都具备稳定分层约定与回归护栏”的状态，重点在于收口统一入口、补齐参数矩阵测试，以及继续压平 setup / maintain / job 的运行时流程。

### Highlights

- 统一 CLI 已稳定分层为 `入口 -> help -> runtime -> forwarding -> validators -> dispatch`
- 新增 CLI 分层约定文档，后续改动有明确落点和回归要求
- 补强了 CLI 参数失败分支、边界参数和帮助输出一致性的测试矩阵
- 继续对 `setup`、`maintain`、`job` 的核心 flow 做函数级拆分，让底层脚本更接近“薄编排 + 小阶段函数”

### Included Improvements

- `bin/lib/help*.sh`、`bin/lib/help_router.sh`
- `bin/lib/validators*.sh`
- `bin/lib/cli_dispatch*.sh`
- `bin/lib/cli_forward_args.sh`
- `docs/refactor/cli-layering-guidelines.md`
- `tests/cli_validators_guard.sh`
- `tests/job_scheduler_guard.sh`
- `tests/setup_runtime_guard.sh`
- `tests/macos_installer_flow_guard.sh`
- `tests/maintain_runtime_guard.sh`

### Bootstrap

全新 macOS 可使用以下命令启动安装：

```bash
BOOTSTRAP_TAG="v0.3.0"
curl -fsSL "https://raw.githubusercontent.com/anzihenry/scripts/${BOOTSTRAP_TAG}/bootstrap/install.sh" | zsh
```

### Notes

- `release publish <tag>` 支持传入裸版本号，例如 `0.3.0`，CLI 会自动规范化为 `v0.3.0`
- 当前推荐的 CLI 回归命令为：
  - `bash tests/syntax_guard.sh`
  - `bash tests/smoke_cli.sh`
  - `zsh tests/cli_dispatch_guard.sh`
  - `zsh tests/cli_validators_guard.sh`
- stable Formula 将指向 `v0.3.0` 源码归档；`brew install --HEAD anzihenry/scripts/macos-scripts` 仍保留给开发版安装场景
