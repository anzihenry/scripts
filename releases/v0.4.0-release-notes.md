## v0.4.0

这个版本把质量基建从"本地手动验证"推进到"CI 自动门禁 + 单一版本来源 + 真实写入集成测试"的阶段，并修复了三个此前未被测试覆盖的真实缺陷：`job create` 生成的 plist 无效、installer 锁在 zsh 下失效、以及干净 runner 上 `maintain brew --dry-run` 因空行解析失败。

### Highlights

- 新增 GitHub Actions CI：语法护栏、lint、smoke 与全部 guard 测试在每次 push/PR 自动运行
- 版本号收敛为单一来源：`VERSION` 文件驱动 CLI、bootstrap 与 Formula，`release verify/publish` 自动校验一致性
- 新增真实文件系统的端到端测试（plist 写入 + `plutil` 校验、brew 错误日志写入、installer 锁目录与卷检测），不再只依赖函数级 mock
- lint 首次归零（处理跨文件共享变量的 SC2034 误报）

### Bug Fixes

- `job create` 生成的 plist 含字面 `\n` 导致 `plutil -lint` 失败：改用 `$'\n'` 并补回命令替换剥离的换行
- `acquire_installer_lock` 在 zsh 中因函数内 EXIT trap 提前触发导致锁立即失效：改为入口脚本全局 trap 统一清理
- `maintain brew --dry-run` 在干净 runner 上因 `brew outdated` 输出空行产生空 cask 名而失败：`awk 'NF'` 过滤空行 + 空元素防御
- `syntax_guard.sh` 依赖未安装的 `rg` 导致护栏静默失效：改用 `find`
- SSH 公钥上传时 token 出现在进程列表：改为临时 config 文件传递，JSON payload 用 python3 转义

### Improvements

- `setup/lib/config_writer.sh` 吸收 `update_shell_config`，删除重复的 `setup_shell_config.sh`
- `resolve_homebrew_bin` 收敛到 `lib/utils.sh` 单一实现
- `job_paths.sh` 支持 `MACOS_SCRIPTS_LAUNCH_AGENTS_DIR` 覆盖，便于测试隔离
- `.gitignore` 补充 macOS 噪音、编辑器备份与缓存模式
- 测试中的版本断言改从 `VERSION` 文件读取

### Bootstrap

全新 macOS 可使用以下命令启动安装：

```bash
BOOTSTRAP_TAG="v0.4.0"
curl -fsSL "https://raw.githubusercontent.com/anzihenry/scripts/${BOOTSTRAP_TAG}/bootstrap/install.sh" | zsh
```
