# v0.3.0 发布清单

本文档用于 `v0.3.0` 发布准备，覆盖版本锚点、发布前验证、tag / GitHub Release 操作，以及 stable Formula 回填步骤。

## 发布目标

- 版本号：`0.3.0`
- Git tag：`v0.3.0`
- 发布分支：`main`
- 发布定位：CLI 分层稳定化 + 测试矩阵补强 + setup / maintain / job 运行时流程收口版本

## 发布前确认

- 工作区变更已审阅完毕，确认没有不应进入 `v0.3.0` 的临时改动。
- [bin/macos-scripts](../bin/macos-scripts) 中的 `MACOS_SCRIPTS_VERSION` 为 `0.3.0`。
- [bootstrap/install.sh](../bootstrap/install.sh) 中的 `BOOTSTRAP_RELEASE_TAG` 默认为 `v0.3.0`。
- [README.md](../README.md) 中 bootstrap、release publish / verify 示例均使用 `v0.3.0`。
- [releases/v0.3.0-release-notes.md](./v0.3.0-release-notes.md) 已与本次发布内容一致。

## 发布前验证

在仓库根目录执行：

```bash
./bin/macos-scripts --version
./bin/macos-scripts release verify 0.3.0 || true
bash tests/syntax_guard.sh
bash tests/smoke_cli.sh
zsh tests/cli_dispatch_guard.sh
zsh tests/cli_validators_guard.sh
zsh tests/setup_runtime_guard.sh
zsh tests/macos_installer_flow_guard.sh
zsh tests/maintain_runtime_guard.sh
zsh tests/job_scheduler_guard.sh
```

验证结果应满足：

- `macos-scripts --version` 输出 `macos-scripts v0.3.0`
- CLI smoke 与新增 guard 全部通过
- bootstrap 文案、release 文案、README 示例均使用 `v0.3.0`

## Tag 与 Release 操作

确认 `main` 已经是待发布提交后执行：

```bash
git checkout main
git pull --ff-only origin main
git add bin/macos-scripts bootstrap/install.sh README.md maintain/github_release_publish.sh releases/v0.3.0-release-notes.md releases/v0.3.0-checklist.md
git commit -m "Prepare release v0.3.0"
git push origin main
git tag -a v0.3.0 -m "Release v0.3.0"
git push origin v0.3.0
```

发布后校验：

```bash
git ls-remote --tags origin | grep "refs/tags/v0.3.0$"
curl -I https://raw.githubusercontent.com/anzihenry/scripts/v0.3.0/bootstrap/install.sh
./bin/macos-scripts release verify v0.3.0
```

## GitHub Release 操作

```bash
./bin/macos-scripts release publish v0.3.0 --yes
```

底层等价命令：

```bash
bash maintain/github_release_publish.sh \
  --tag v0.3.0 \
  --notes-file releases/v0.3.0-release-notes.md \
  --update-existing \
  --yes
```

## Stable Formula 回填

由于 GitHub 源码归档 `sha256` 需要基于远端 `v0.3.0` tarball 计算，打完 tag 后再更新 [Formula/macos-scripts.rb](../Formula/macos-scripts.rb)：

```bash
curl -L https://github.com/anzihenry/scripts/archive/refs/tags/v0.3.0.tar.gz -o /tmp/macos-scripts-v0.3.0.tar.gz
shasum -a 256 /tmp/macos-scripts-v0.3.0.tar.gz
```

然后把 Formula 中的 `url` / `sha256` 更新到 `v0.3.0`，再补一次提交推送到 `main`。

## 发布后检查

- 确认 `curl .../v0.3.0/bootstrap/install.sh | zsh -s -- --dry-run` 可以正常运行
- 确认 release 页面文案与 [releases/v0.3.0-release-notes.md](./v0.3.0-release-notes.md) 一致
- 完成 Formula 回填后，再次验证 `brew install anzihenry/scripts/macos-scripts` 指向 `v0.3.0`
