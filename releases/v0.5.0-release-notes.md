## v0.5.0

这个版本把质量基建从"CI 自动门禁"再推进到"发布前进程级 E2E 门禁"：新增不依赖真实环境的沙箱命令桩端到端测试，并新增打 tag 即触发的 `release.yml` 发布门禁，在全新 macOS VM 上同时执行真实流程校验与 Formula 实装。同时修复了 E2E 首次跑出的两个 `set -e` 隐藏缺陷。

### Highlights

- 新增进程级 E2E（`tests/e2e/`）：沙箱重定向 HOME/配置/日志/LaunchAgents，命令桩（brew/launchctl/gh/git/curl 等）记录外部调用，跑真实脚本全流程并断言产物文件、调用序列与退出码
- E2E 覆盖 7 条真实流程：`job create/list/disable`、`release verify/publish`、`maintain brew`、`bootstrap install`，一键执行 `bash tests/e2e/run_all.sh`
- 新增 `release.yml` 发布门禁：打 `v*` tag 时自动执行全量 guard + lint + smoke + E2E，并在 `macos-latest` 上真实运行 `release verify`、各 `--dry-run` 与 Formula 实装校验
- `ci.yml` 接入 E2E，每次 push/PR 自动运行

### Bug Fixes

- `job list` 在存在任务时返回退出码 1：zsh 中 `((count++))` 首次自增返回旧值 0（假），在 `set -e` 下触发 errexit 提前退出；改为 `count=$((count + 1))`
- `ensure_xcode_cli_installed` 等待循环同样存在 `((wait_count++))` errexit 隐患，一并修复
- bootstrap 管道模式（`curl ... | zsh`）下 `utils.sh` 不可用时补充自包含 fallback，避免解析路径失败

### Improvements

- `tests/e2e/` 提供命令桩扩展点：新增 `shims/<cmd>` 并实现记录 + 行为即可覆盖新命令
- 发布清单（checklist）与 README 补充 E2E 运行步骤，作为每次发布前必跑项

### Bootstrap

全新 macOS 可使用以下命令启动安装：

```bash
BOOTSTRAP_TAG="v0.5.0"
curl -fsSL "https://raw.githubusercontent.com/anzihenry/scripts/${BOOTSTRAP_TAG}/bootstrap/install.sh" | zsh
```
