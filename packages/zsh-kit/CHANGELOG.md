# zsh-kit 变更记录

## 0.2.0 — 待发布

- 非法参数在副作用前返回 2；布尔值只接受 true/false，显式空值不再被解释为默认值。
- `API.txt` 定义公开函数；非公开实现统一 `_sk_` 前缀。直接使用原内部函数的消费者需要改用公开接口。
- 新增 `sk_commit_config_candidate` 高级接口；调用方须在读取/生成候选文件前持有目标资源锁。
- `sk_start_capture path [merged|separate]` 新增 separate 模式；省略第二参数保留旧的合并输出行为。
- 独立测试验证公开接口集合、重复加载、分离通道、非法参数无副作用与原子提交。

升级：审阅此记录及 README，使用可信的离线同步工具更新固定快照，再运行调用方测试。0.2.0 尚未创建 tag 或对外发布；应用 macos-scripts 的版本独立维护。

## 0.1.0 — 仓库初始快照

- 从 macOS 脚本项目抽离日志、执行、流程、锁和配置写入组件。
- 提供独立契约测试和离线 vendor；初始快照保存在独立文件整理示例中。
